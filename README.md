# parfumerie-issue-assets

Public image host for [niteeshm/parfumerie](https://github.com/niteeshm/parfumerie) issues.

GitHub issue bodies are rewritten through **Camo**, which fetches `<img>` URLs **without** your GitHub session. Files in the private `parfumerie` repo therefore render as broken images. Images here are public so they actually show up.

Do not put secrets, tokens, or personal data in this repo.
